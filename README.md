# Portal ESFAP (prototipo) – Spring Boot

Importar en Spring Tool Suite: File > Import > Maven > Existing Maven Projects > carpeta `portal-esfap`.
Ejecutar: clic derecho en `PortalApplication` > Run As > Spring Boot App. Abrir http://localhost:8080
Pruebas: Run As > JUnit Test. Requiere JDK 17+.

**Primer arranque:** las contraseñas iniciales son aleatorias y se muestran UNA vez en la consola. Deberá cambiarlas al ingresar.

Módulos de esta versión: matrícula virtual, mesa de partes con cargo digital, seguimiento de documentos
(interno y consulta pública), niveles de seguridad N1–N4 y auditoría con integridad verificable.
Detalle, trazabilidad RF-01…RF-07 y pendientes en `docs/DOCUMENTACION.md`.
